## 五段式「拍摄计划」框架

每个分镜的视觉层不是若干孤立字段的描述，而是一份完整的拍摄计划：按 **主体 → 动作 → 运镜 → 光 → 声** 五段各回答一个问题，合起来即可直接开拍。五段与视觉字段一一对应：

- **主体**——画面里是谁 / 什么：image_prompt.scene 的主体层（姿态 / 表情 / 服装）+ video_prompt.action 里的主体动作。
- **动作**——这段时长里发生什么变化：video_prompt.action（物理可观察、与时长匹配）。
- **运镜**——相机在哪、怎么动：image_prompt.composition.shot_type + video_prompt.camera_motion（按画面内容从枚举选择，不强加倾向）。
- **光**——光从哪来：image_prompt.composition.lighting（光源 / 方向 / 色温）+ video_prompt.action 里的光影移动。
- **声**——画内听到什么：video_prompt.ambiance_audio（画内音）。

图片是拍摄计划的单帧切片：主体与光是图片段的两个核心，运镜由构图字段承载，动作与声两段由视频字段补齐——五段在两个字段组之间分工，不重复、不缺位。五段结构对所有题材共用（SFW / NSFW 一律）：题材差异只体现在动作段的措辞精度（成人向题材写更具体的物理动作，不写抽象情绪），不增不减段。

正例（8 秒剧情分镜走一遍五段）：主体——「@[林清]坐在窗边木桌前，左手撑着下巴」；动作——「她缓缓抬起头，手指无意识地摩挲信纸边缘」；运镜——相机贴近、缓缓向她的侧脸推近；光——「右侧落地窗逆光的蓝灰色阴影」；声——「雨丝拍在木格窗棂，远处一声闷雷」。五段各有一笔，按序合起来即一份可执行的拍摄计划。

反例（缺段 / 混段）：「林清在窗边，画面很忧郁，氛围感拉满。」——只有主体的抽象标签，没有动作、没有相机位置、光只有一句情绪词、没有声；五个问题一个都没回答，不构成可拍摄的方案。
