## 显性接触单元（L4+）七条必备条款

**触发条件**：单元的正文带 `[接触 L4 · <体位> · 支撑：<点>]` 或 `[接触 L5 · …]` 标记。L4 以下（无标记）不引入这些条款，按普通五段式扩写。

> **体位决策点在 `script_plan` 阶段**：plan 的标记行 `[接触 L4 · 体位 · 支撑]` 就是结构化契约 token，下游（prompt / AD）只**继承**、不重新决策体位。`validate_pose_plan_alignment` 逐字比对 prompt 标记行与 plan 标记行，漂移即违约——本段条款描述的是"继承后如何落地"，不是"选哪个体位"。

参考生视频模式下正文是唯一空间规格——没有分镜起始帧锚定姿态。凡正文没写死的空间自由度，模型都用先验分布填充：「交叠」的先验是相拥 / 对坐，遮挡区域未描述的肢体先验是「不画」。L4+ 单元正文必须七条款齐全，缺一即机械校验拒绝：

1. **骨架声明**——主体段首句写死：体位类型 + 上下位分配 + 全部支撑点，且首句即 `[接触 …]` 标记行本身。
   例：`@[克劳德/全裸] 位于她上方，双膝跪在床面、双臂撑在她头侧床面、骨盆与她的骨盆对齐贴合`
2. **肢位表**——双人每肢各给一个解剖位置，禁关系词：头、双臂、双手、双腿、双脚、骨盆，六组 × 两人全覆盖。用「谁在上、下方人的膝盖 / 腿 / 脚在哪、上方人的膝 / 大腿 / 骨盆 / 手撑在哪」的解剖位置词（双腿打开、脚掌踩床面、大腿贴她大腿内侧）。
3. **易掉肢体完整性声明**——遮挡区肢体（下方人双腿 / 脚、相拥时的脸）显式二选一：「双腿完整、双脚踩在床面全程保持在画面内」或「双脚在画面下缘外、始终存在于床面」。
4. **运动几何化**——一切动作写成骨盆 / 关节运动学：幅度（cm）、频率（秒/次）、相位、节奏曲线（如「前半段幅度小节奏慢，后半段幅度与频率渐增」），节奏曲线必须与单元时长匹配；动作节拍内对易漂锚点复锚一次（如「双脚踩在床面不动」）。
5. **取景下界（master shot 原则）**——运镜段声明框住双人全身的景别下界（如「固定中景，双人全身入画」），或显式列出出框肢体；取景与条款 3 的声明不得矛盾（近景裁脚 + 声明脚在画面内 = 必丢脚）。默认最优机位：45° 对角中景（同时露出双人面部与关系）；180° 轴线锁定在双人一侧，越轴 = 位置互换感，禁用。
6. **措辞表**——全单元只用下方替换表的几何化措辞，黑名单词零出现；同集所有 L4+ 单元口径统一，不混用。
7. **连续性（姿态锁）**——连续 L4+ 单元的主体段骨架句（标记行）逐字一致，只允许改运动量段（幅度 / 频率 / 表情 / 节奏）；换体位必须是独立单元边界，不得在单元内切换。

### 关系词黑名单（L4+ 单元正文零出现）

交叠、相拥、拥抱、依偎、对坐、覆身、趴压、骑跨、缠绕、交缠、紧贴、压住、插入、抽插、推入、抽出、顶入

（「骑跨」若必须表达，改写为「双膝跪在她髋部两侧床面、大腿分开贴她大腿外侧」。）

### 敏感词替换表

| 原措辞 | 几何化 / 合规替代 |
|---|---|
| 插入 / 推入 / 推至最深处 | 骨盆缓慢下压至最低点 |
| 抽出 / 退出 | 骨盆完全抬起 |
| 抽插 / 连续抽插 | 骨盆律动（写明幅度 cm + 频率 秒/次） |
| 送到最深处 | 骨盆下压至最低、床品凹陷回弹 |
| 高潮 | 身体一波波张力（腹部 / 喉结 / 咬肌收紧）+ 面部（眼 / 唇）+ 呼吸频率变化 |
| 内射 | 身体持续紧绷 + 屏息 + 胸腔起伏 + 一声压低轻哼 |
| 呻吟 | 可保留，但必须附呼吸频率描述（如「频率每两秒一次」） |

### 正例（五段 + 七条款按序，15 秒 L4 单元）

「主体：`[接触 L4 · 传教士体位 · 支撑：双膝+双臂]` @[克劳德/全裸] 位于她上方，双膝跪在床面、双臂撑在她头侧床面、骨盆与她的骨盆对齐贴合。她的头枕在枕面、双臂环过他后颈、双手插进他后发、双腿打开贴他双腿内侧、双脚脚掌踩在床面、骨盆与他对齐贴合；他的头低靠她肩侧、双臂撑床、双手按在她腰侧床面、双膝跪在床面、双脚脚背贴床面。她的双腿完整、双脚踩在床面全程保持在画面内。
动作：他的骨盆以 3 cm 幅度、每 1.5 秒一次下压，前半段节奏慢，后半段幅度渐增至 6 cm、频率渐密至 1 秒/次；她的骨盆相向贴合、腰随之小幅度起伏；他的双脚脚背贴床面不动。
运镜：固定中景，45° 对角机位，双人全身入画，焦点在两人骨盆贴合处。
光：床头暖灯侧光，光影随骨盆起伏缓慢移动。
声：床品摩擦声、两人呼吸声（频率随节奏曲线变化）。」

### 反例（缺条款）

「两人身体交叠在床面上。」——一个关系词，零骨架、零肢位、零支撑点、零取景声明：模型按「交叠」先验填相拥 / 对坐，遮挡区肢体不画。
